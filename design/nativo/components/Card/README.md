Card is the plain container for one idea: a benefit, a fact, a plant.

**You provide:** a title, a short paragraph and, optionally, a tag (a Badge) above the title.

**Anatomy**
- `paper` fill, `border-2` in `line`, `--radius-card` (24), `--shadow-5`, `--card-pad` padding.
- Tag at the top left, then the title in display type at `--type-h3-card`, then text at `--type-body-sm`, `space-8` apart.
- Align everything to the left.

**Do**
- Set cards in a two-column grid and drop every second one by `space-32` for a staggered rhythm.
- Pair a set of cards with one StickyNote for the aside.

**Don't**
- Tilt a card. Tilt belongs to sticky notes.
- Fill a card with a colour. Coloured surfaces are windows, notes and bands.

Live example: the "Why a native yard" section of the landing page.
