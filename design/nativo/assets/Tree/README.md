2 tree illustrations, each in two colorways: two whole trees: a bare winter tree (01) and a full-canopy tree (02).

**Files:** `tree-NN-green.svg` is drawn in `green` for use on `cream`, `paper`, `sand`, `meadow`, `sky`, `peach` and `gold` grounds. `tree-NN-cream.svg` is drawn in `cream` for use on `green`, `green-deep` and `clay` grounds. The two files of a number are the same drawing.

**Ink:** each file is a single flat color, `#2E6850` (green) or `#F6F3EA` (cream). Pictures show only through `<img>`, which cannot read tokens, so the colors are fixed in the file.

**Use**
- Place one drawing per section or card, beside a heading or under a short intro, at most half the width of its column.
- Keep the drawing's natural proportions. Do not stretch, crop, rotate or recolor it.
- Use at most one tree drawing per section or card.
- Give it empty alt text (`alt=""`) when it is decoration.
