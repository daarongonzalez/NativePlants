13 branch illustrations, each in two colorways: leafy and flowering branches: upright sprigs (01 to 06), horizontal branches (07 to 13).

**Files:** `branch-NN-green.svg` is drawn in `green` for use on `cream` and `gold` grounds. `branch-NN-cream.svg` is drawn in `cream` for use on `green` and `clay` grounds. The two files of a number are the same drawing.

**Ink:** each file is a single flat color, `#2E6850` (green) or `#F6F3EA` (cream). Pictures show only through `<img>`, which cannot read tokens, so the colors are fixed in the file.

**Use**
- Place one drawing at the bottom of a `BentoTile` as its media, left-aligned, at most half the tile's width.
- Keep the drawing's natural proportions. Do not stretch, crop, rotate or recolor it.
- Use at most one branch drawing per tile.
- Give it empty alt text (`alt=""`) when it is decoration.
